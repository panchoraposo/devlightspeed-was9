FSI KYC Onboarding

Red Hat Build of Quarkus 3 — REST replacement for the legacy WAS9 JAX-WS KYC SOAP service. Audit tokens use SHA-256.

REST API (from SOAP)

SOAP operationHTTPPath
submitApplication POST /api/kyc/applications (alias: /api/kyc/submit)
getStatus GET /api/kyc/applications/{applicationId} (alias: /api/kyc/status/{applicationId})

Request/response JSON uses the same fields as the SOAP payloads: fullName, nationalId, country, riskScore → applicationId, status, reason, auditToken.

curl -s -X POST http://localhost:8090/api/kyc/applications \
  -H 'Content-Type: application/json' \
  -d '{"fullName":"Ana Perez","nationalId":"CL-12345678","country":"CL","riskScore":12}'

curl -s http://localhost:8090/api/kyc/applications/KYC-XXXXXXXX
